# LeanType Offline RU

Неофициальная модификация Android-клавиатуры [LeanType](https://github.com/LeanBitLab/LeanType) с автоматической вставкой SMS-кодов и улучшенными контекстными подсказками на русском языке.

Проект создан для личного использования и опубликован в открытом доступе.

## Почему я это сделал

После перехода с iPhone на Android меня раздражала одна вещь: на iPhone коды подтверждения из SMS удобно появлялись над клавиатурой, а на Android это работало далеко не всегда.

Мне хотелось, чтобы входящий SMS-код автоматически появлялся в строке подсказок и его можно было вставить одним нажатием, независимо от того, поддерживает ли конкретное приложение стандартное автозаполнение Android.

В итоге я решил навайбкодить собственное решение на основе открытой клавиатуры LeanType. Заодно добавил более продвинутые контекстные подсказки на русском языке.

Никакого большого проекта из этого делать не планировал — просто сделал то, чего мне самому не хватало, и решил поделиться исходниками (может пригодятся кому-то).

**Проверено на:** CMF Phone 1, Android 16 (Nothing OS 4.0).

На других устройствах и версиях Android работоспособность не проверялась.


## Возможности

### Автоматическая вставка SMS-кодов

- Автоматическое распознавание одноразовых кодов из входящих SMS.
- Отображение кода в панели подсказок клавиатуры.
- Вставка кода одним нажатием.
- Автоматическое удаление кода из памяти через 120 секунд.
- Не требуется доступ к истории SMS.

Функция использует разрешение `RECEIVE_SMS` и включается в настройках клавиатуры.

### Русские контекстные подсказки

- Предсказание следующего слова с учётом предыдущих слов.
- Локальная модель на основе биграмм и триграмм.
- Персональная история ввода.
- Совместная работа с существующей системой автокоррекции.

Все предсказания обрабатываются непосредственно на устройстве, без подключения к интернету.

## Установка

Готовую сборку APK можно скачать в разделе [Releases](https://github.com/alexbortamski-ui/LeanType-Offline-RU/releases).

После установки включите LeanType в настройках клавиатур Android и выберите её в качестве основного способа ввода.

Для работы с SMS-кодами необходимо включить соответствующую функцию и предоставить разрешение на получение SMS.

## Сборка из исходников

Необходимы JDK 17, Android SDK (compileSdk 36) и Android NDK 28.0.13004108.

Сборка на Windows:

```powershell
.\gradlew.bat :app:assembleOfflineDebug
```

Сборка на Linux:

```bash
./gradlew :app:assembleOfflineDebug
```

Готовый APK будет находиться в `app/build/outputs/apk/offline/debug/`.

## Конфиденциальность

Клавиатура работает без доступа к интернету.

Обработка вводимого текста, формирование подсказок и распознавание SMS-кодов выполняются локально.

Одноразовые SMS-коды временно хранятся в оперативной памяти и не добавляются в историю буфера обмена.
